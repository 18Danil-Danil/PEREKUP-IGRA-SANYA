# 🚗 Симулятор Перекупа

Мобильный симулятор перекупа авто — веб-версия (PWA-friendly). Работает на телефоне, можно добавить на главный экран.

## Играть

Откройте: `https://ВАШ_НИК.github.io/perekup-sim/`

## Возможности

- 🚗 Рынок AvtoBuy с торгом и скрытыми дефектами
- 🔍 Осмотр через толщиномер / OBD-сканер
- 🔧 Гараж: ремонт и 17 видов тюнинга
- 🔢 Блатные номера
- 💬 Живые чаты с родными (мама, бабушка, дедушка)
- 🎰 Казино: слоты, кейсы, мины, кости
- 🏠 Недвижимость с пассивным доходом
- 🚕 Таксопарк (найм водителей на свои машины)
- 💤 Сон (скип времени)
- 🏦 П-Банк: кредиты и статистика

## Как запустить локально

Просто откройте `index.html` в браузере. Всё работает оффлайн, сохранение — в localStorage.

## Как обновлять

Версия сейва зашита в `Game.SAVE_VERSION` (`js/game.js`). При повышении версии старый прогресс сбрасывается автоматически.
