# 🚗 Симулятор Перекупа

Мобильный симулятор перекупа авто — веб-версия (PWA-friendly).

## Играть

Откройте: `https://ВАШ_НИК.github.io/perekup-sim/`

## Возможности (v3.0)

- 🚗 **AvtoBuy** — рынок, торг, скрытые дефекты, осмотр через толщиномер / OBD
- 🔧 **Гараж** — ремонт, 17 видов тюнинга
- 💼 **Работа** — 5 подработок: крановщик, мойка, курьер, стройка, дальнобойщик
- 🏦 **П-Банк** — кредиты, статистика
- 🔢 **Номера** — рынок блатных номеров
- 🏛 **Аукцион** — лоты против ботов + портовые контейнеры
- ✈️ **Импорт** — Япония / Корея / Китай / ОАЭ
- 🏠 **Недвижимость** — пассивный доход
- 🚕 **Таксопарк** — найм водителей
- 🎰 **Casino** — Краш, Слоты, Блэкджек, Рулетка, Кейс, Мины
- 🪪 **ГосBuy** — паспорт, права, ПТС, налоги, штрафы
- 👨‍👩‍👧 **Родные 2.0** — дни рождения, события, живые чаты, «Заехать в гости»
- 💬 **Сообщения** — личные чаты с продавцами

## Экономика

Старт: 100 000 ₽. Работа = 5–20k за смену. Купил дёшево — вложил в ремонт/тюнинг — продал дороже. НДФЛ 13% с прибыли копится в долг и оплачивается в ГосBuy.

## Локально

Просто откройте `index.html`. Сохранение — localStorage. Версия сейва в `Game.SAVE_VERSION` — при апдейте старый прогресс сбрасывается автоматически.
